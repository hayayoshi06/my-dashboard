⚙ 設定

天気は通常ブラウザの位置情報から現在地を自動取得します。位置情報の利用を許可できない場合は、ここで都市名を指定すると手動設定が優先されます。
先に上の「地域を検索して保存」で地域を設定してから、名前を付けてプリセットに登録できます。登録後はタップで切り替えられます。
Google Cloud Console で OAuth クライアントID と APIキーを発行し、Calendar API・Google Sheets API を有効化してください。 ここで入力した値はこのブラウザの localStorage にのみ保存され、リポジトリには保存されません。 普段は内容が隠れた状態で表示されます。
Googleに接続すると一覧を取得できます
何も選択しない場合はメインカレンダー（primary）のみ表示します。複数選択すると、まとめて今日の予定を表示します。
スプレッドシートのURL（https://docs.google.com/spreadsheets/d/【ここがID】/edit）からIDをコピーして貼り付けてください。 シート（タブ）名は「HealthData」にし、1行目を見出し（日付・歩数・距離km・アクティブエネルギーkcal・睡眠時間h・心拍数bpm・体重kg）にしてください。 同じスプレッドシート内に「AppSync」という名前のタブが自動作成され、TODO・クイックメモをGoogleアカウントでログインした端末間で同期するのに使われます。 スプレッドシートは非公開のままでよく、上記のGoogle認証でご自身のログイン時のみ読み書きします。
健康データ送信で使っているApps ScriptのWebアプリURLと同じものを入力してください（同じスクリプトにニュース取得用の受け口を追加して使い回します）。 外部の無料中継サービス（rss2jsonなど）が不安定なため、Apps Script経由でGoogleニュースのRSSを取得する方式に変更しました。設定方法はREADMEを参照してください。
カンマ区切りでキーワードを登録すると、見出しにそのキーワードを含む世界情勢・AI関連ニュースを表示しないようにできます。
TODOリストや地域・Google設定などはこのブラウザだけに保存されています。ブラウザのデータを消去したり端末を変えたりする前に、書き出しておくことをおすすめします（Google APIキー等の秘密情報も含まれるため、ファイルの取り扱いにはご注意ください）。
